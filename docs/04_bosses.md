# 特徴ボス仕様

## 出現順と共通ループ

1・2体目は従来型の通常ボス、3体目は特徴ボスとして出現する。この3体セットを繰り返す。
特徴ボスだけを数えると `リバーサ → スナイパー → ショウグン → タンク → プリースト` の固定順となるため、プリーストは15体目に必ず登場する。
3体ごとの特徴ボスは強敵扱いとなり、撃破後に特別強化の2択を表示する。

通常ボスは回転・逆回転・全方位リングの従来弾幕から抽選し、ランダム弾は使用しない。

ボス出現時は敵と残弾を消して安全な空戦場へ遷移する。複数体や付属敵を含む戦闘は、`BossEncounter` がまとめて1回のボス戦として管理する。

## リバーサ

- 2.5秒後に最初のイベントを開始。6秒継続し、解除して通常状態へ戻った後、1.5秒の空白を置いて次を抽選する。
- 同じイベントは連続抽選しない。切替時は敵弾を消す。
- A「上下反転」：自機を上、ボスを下へ移し、互いの弾方向も反転する。
- B「攻撃反転」：自弾命中でボスが回復し、命中していない時間は毎秒11ダメージを受ける。
- C「操作反転」：方向入力とドラッグ目標を上下左右反転する。

## スナイパー

- 3体で構成し、各個体のHP合計を通常ボス相当にする。
- 各個体は時間差でプレイヤー狙いの高速弾を撃つ。
- 発射後1.7秒だけ姿と当たり判定が現れ、それ以外は不可視・自弾透過となる。

## ショウグン

- 画面左右から交互に、低密度の横断弾を常時発射する。
- 本体前方に大型の壁役を置く。壁は低頻度の狙い弾を撃ち、破壊されるまで本体は攻撃不能。
- 壁破壊後、プレイヤーが画面下半分なら3方向狙い弾を撃つ。
- 上半分なら19発を0.035秒ずつずらした扇で刀波を表現する。

## タンク

- 通常ボスの2.35倍のHPを持つ。
- HPを20%失うごとに装甲段階が上がり、基礎弾速と弾サイズが少しずつ増える。
- 段階2・4で密度が上がる。
- 段階3では低速・小型・1回跳弾へ変化する。段階4で解除し、3秒かけて通常性能へ戻る。

## プリースト

- HPが1/4より多い間は、6秒ごとにA/Bを交互に切り替える。
- A「追跡祈祷」：プレイヤーへ低速追跡し、低速狙い弾を連射する。
- B「加速する祈り」：0.75秒ごとに敵弾数を確認し、18個以下なら加速跳弾を1発出す。弾は反射ごとに1.22倍速くなり、上限速度へ達するまで残る。
- C「決闘」：HP1/4で必ず発動。被ダメージを半減し、その時点の自機弾幕を上限付きでコピーする。近くの自弾から離れるように移動する。
- コピー上限：7方向、速度340、弾半径7。連射間隔は0.085秒より短くしない。

## dev-loop

開発環境または `?debug` 付きURLのデバッグパネルから以下を即時実行できる。

- 通常ボスと5種それぞれの特徴ボスへ即時差し替え
- 現在ボスの次イベントを発動
- リバーサA/B/Cを個別発動
- プリーストA/B/Cを個別発動
- 従来の被弾、無敵、弾消し、武器強化など

主要ロジックは `src/run/bosses.ts`、統合テストは `tests/run/bosses.test.ts` に置く。
