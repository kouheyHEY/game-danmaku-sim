# 特徴ボス仕様

## 出現順と共通ループ

1・2体目は従来型の通常ボス、3体目は特徴ボスとして出現する。この3体セットを繰り返す。
特徴ボスだけを数えると `リバーサ → スナイパー → ショウグン → タンク → プリースト` の固定順となるため、プリーストは15体目に必ず登場する。
3体ごとの特徴ボスは強敵扱いとなり、撃破後に特別強化の2択を表示する。

通常ボスは回転・逆回転・全方位リングの従来弾幕から抽選し、ランダム弾は使用しない。
通常ボス・特徴ボスとも表示と当たり判定を小さくし、強化された自機弾幕に耐えられるようHPを従来より高くする。

通常ボスは雑魚と残弾を残したままシームレスに出現する。3体ごとの特徴ボスだけは敵と残弾を整理して専用戦場へ遷移する。複数体や付属敵を含む戦闘は、`BossEncounter` がまとめて1回のボス戦として管理する。

## リバーサ

- HPが半分より多い間は、画面下方向のランダムな角度・速度で弾幕を放つ。
- HPが半分以下になると「反転弾幕」へ移行する。その時点で画面内にあるリバーサ弾は、元の速度から徐々に減速し、停止を挟んで逆向きへ加速する。
- 反転弾幕へ移行した後、リバーサ本体は弾を発射しない。代わりに画面下端の外側から弾がランダムな位置に自然発生し、リバーサへ向かって上昇する。
- 後半は「リバーサが撃つ」のではなく、画面全体の弾幕の流れが上下反転したように見せる。
- 戻った弾はリバーサ付近で吸収される。瞬間的な反射にはせず、反転中も当たり判定を維持する。
- 3体ごとの強敵枠、撃破後の特別強化2択、特徴ボスの出現順は維持する。

## スナイパー

- 3体で構成し、各個体のHP合計を通常ボス相当にする。
- 3体は射撃して姿を現すたび、画面上部のランダムな位置へ移動する。
- 各個体は時間差でプレイヤー狙いの高速弾を撃つ。
- 発射後2.4秒だけ姿と当たり判定が現れ、それ以外は不可視・自弾透過となる。

## ショウグン

- 画面の左右・高さを1発ごとにランダム抽選し、0.1〜0.2秒間隔で横断弾を常時発射する。
- 本体前方に大型の壁役を置く。壁は低頻度の狙い弾を撃ち、破壊されるまで本体は攻撃不能。
- 壁破壊後、プレイヤーが画面下半分なら3方向狙い弾を撃つ。
- 上半分へ入った瞬間に刀波を発動する。21発を0.01秒ずつずらして短時間で切り抜ける軌道を表現し、上半分にいる間の再発動間隔も1.1秒にする。

## タンク

- 特徴ボス基準の3倍のHPを持つ。
- HPを20%失うごとに装甲段階が上がり、基礎弾速と弾サイズが少しずつ増える。
- 初期弾速・段階ごとの弾速と弾サイズ・発射頻度を従来より高くし、段階2・4でさらに密度が上がる。
- 段階3では弾速を維持したまま小型・1回跳弾へ変化する。段階4で解除し、3秒かけて弾サイズが通常性能へ戻る。

## プリースト

- HPは特徴ボス基準値の4.2倍。見た目はプレイヤー本体とほぼ同じ大きさで、他のボスと異なる緑色にする。当たり判定は小さいまま維持する。
- A「追跡祈祷」：HPが65%より多い間。プレイヤーへ高速で追跡し、10回まで画面端で跳ね返る狙い弾を連射する。
- B「旋回する祈り」：HPが25%より多く65%以下の間。画面中央へ移動し、到着後はその位置に固定する。約1.8秒ごとに36発の低速弾を等間隔の全方位へ同時発射し、斉射ごとに開始角度を半ピッチずらす。弾は発射後3秒間、斉射ごとに左右交互の方向へ速度ベクトルが曲がり、その後は直進して画面外へ抜ける。
- C「決闘」：HP25%以下で必ず発動。被ダメージを半減し、その時点の自機弾幕を上限付きでコピーする。近くの自弾から離れるだけでなく、短い横移動で弾を抜け、壁際では内側へ切り返す。
- コピー上限：最大5方向（偶数弾は4方向）、速度280、弾半径4。連射間隔は0.12秒より短くしない。

## dev-loop

開発環境または `?debug` 付きURLのデバッグパネルから以下を即時実行できる。

- 通常ボスと5種それぞれの特徴ボスへ即時差し替え
- 現在ボスの次イベントを発動
- リバーサ戦中の「次イベント」はHP半分の反転弾幕を即時発動
- プリーストA/B/Cを個別発動
- 従来の被弾、無敵、弾消し、武器強化など

`?debug&bossrush` では雑魚・通常ボスを省き、5種の特徴ボスだけを1.2秒間隔で連戦する。各撃破後は特別強化2択へ進む。デバッグパネルの「大ボス連戦開始」でも同じモードへ切り替えられる。

主要ロジックは `src/run/bosses.ts`、統合テストは `tests/run/bosses.test.ts` に置く。
