# 方針転換2：極限までシンプルなエンドレス回避

> 既存の `World`/`step()`/弾幕ライブラリ/被弾-復帰演出はそのまま再利用。
> ローグライトの「敵列＋3択リワード」は撤去する。

## コアループ（ワンフィンガー）

1. 起動 → **「Tap to Start」だけ**表示。タップで開始。
2. 次々に出現する**大ボスの弾幕**を、**ドラッグでひたすら避ける**。
3. 自機は**自動発射**。攻撃操作は不要。
4. 雑魚フェーズはなく、**大ボスだけが連続出現**する。自弾で撃破すると **HP+1回復** ＆ **特別強化の2択**。
5. 被弾で HP-1（その場で弾消し波動→画面下から点滅復帰）。HP0 で **ゲームオーバー → TOP10ランキング表示 → タップで再開**。

## スコア

**（敵に与えた実ダメージ＋かすり回数×10）×スコア倍率**（画面右上）。倍率は1.0から始まり、プリースト撃破ごとに1.2倍される（`1.2 ^ プリースト撃破数`）。大きな数値は指数表記にする。

特別強化にはレベルを設ける。武器系強化が上限に達すると同名強化は候補から外れ、代わりに「凝縮」が候補へ入る。凝縮は対象能力を初期値へ戻し、弾数・速度・連射・サイズの蓄積倍率を威力へ変換してレベルを0へ戻す。これにより転生後も再び強化でき、武器成長に実質的な上限を持たせない。HP系のライフコアは上限なしとする。

ゲームオーバー時に順位・スコア・到達ボス・転生回数（プリースト撃破数）を記録し、`localStorage`による端末内ランキングの上位10件を表示する。オンラインランキングは公開後の拡張として扱う。

## ドメインの最小追加

- 敵弾は自機の半径22px以内へ入ると、一発につき一度だけ「かすり」として記録する。
- `Session.scoreBase`：与えた実ダメージ＋かすり得点。
- `Session.scoreMultiplier`：プリースト撃破数から求める倍率。
- `Session.score`：`Session.scoreBase × Session.scoreMultiplier`。
- 大ボス撃破後はランダムに提示された特別強化2つから1つを選ぶ。

## レイヤ

```
Session（run/session.ts） title / playing / gameover の状態機械
  ├ BossEncounter          5種の特徴ボスと複数個体を1戦として管理
  └ randomWeaponUpgrade    撃破時にランダムで武器強化
World/step（domain）        弾・敵・自機の移動、命中、かすり判定
SessionRenderer（render）   弾/自機/ボスHP＋右上スコア＋Tap to Start／GameOver
```

反転(①〜④)・敵列・3択は撤去（コードは履歴に残る）。まずは「触ってすぐ・ずっと避ける」体験に一本化する。
