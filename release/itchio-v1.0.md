# Danmaku Sim v1.0.0

## Short description

避けて、倒して、弾幕を凝縮する。5体の個性派ボスと戦う縦画面弾幕シューティング正式版。

## Description / 説明

指一本で避けて、倒して、弾幕を育てる。

Danmaku Simは、5種類の大ボスと連続で戦う縦画面弾幕シューティングです。自機は自動射撃。ドラッグまたは十字キーで弾幕を避け、ボス撃破後の特別強化で自分の弾幕を育てながらハイスコアを目指してください。

### v1.0.0

- 全画面表示の高解像度化
- 日本語・英語共通ピクセルフォント
- プリースト撃破倍率1.2倍
- レベル制の特別強化と、上限後の凝縮・再育成
- 上限なしのライフコア
- 転生後も続く敵・弾幕・スコア倍率・自機強化
- 端末内TOP10ランキング

操作：タップで開始／ドラッグまたは十字キーで移動／射撃は自動／P・Escまたは左上ボタンで一時停止。

English release notes are available on the GitHub release page. The game supports both touch controls and arrow keys, automatic fire, scalable upgrades, rebirth progression, and a local top-10 leaderboard.
